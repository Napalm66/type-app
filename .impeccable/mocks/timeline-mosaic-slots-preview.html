Era mosaic — image slot map

Each tile below is one image slot, named era-{slug}-{n}.jpg — slot 1 is always the largest/"hero" tile for that era, slots 2+ are the progressively smaller supporting tiles the recursive split cascades into. Sized to the era's opened (widest) state, since that's the largest any tile ever renders at — the same image scales down cleanly for the narrower resting width, so one square master per slot covers both states via crop-to-fill.
